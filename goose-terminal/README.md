# Goose Terminal

Block's [Goose](https://github.com/block/goose) CLI AI agent in a web terminal, wired to Google Gemini, as a Home Assistant add-on.

Add a Google Gemini API key in the add-on configuration, start the add-on, and open the terminal from the sidebar to start an agent session.

See [DOCS.md](DOCS.md) for full configuration and usage.
